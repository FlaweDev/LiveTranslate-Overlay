# 🎙️ LiveTranslate-Overlay

**LiveTranslate-Overlay** — это программа для автоматического распознавания речи и живого перевода системного звука в реальном времени. Она захватывает любое аудио с вашего компьютера (видео, стримы, голосовые звонки, игры, лекции), разделяет голоса разных людей и выводит плавные двуязычные субтитры прямо поверх всех окон.

Оверлей абсолютно прозрачен для кликов мыши — вы можете продолжать играть, работать или смотреть видео, не отвлекаясь на переключение окон, а полное полотно диалога всегда доступно в отдельном окне «Истории реплик».

## ⚙️ Как это работает?

Весь процесс происходит локально на вашем компьютере без отправки звука в интернет:

1. **Захват и распознавание (2 аудио-модели):** Программа перехватывает системный звук с ваших динамиков или наушников. Две нейросети от NVIDIA работают параллельно: первая распознает произнесенные слова, а вторая определяет, кто именно сейчас говорит (разделяет до 4 спикеров одновременно, окрашивая их реплики в разные цвета).
2. **Живое отображение:** Как только человек произносит слова, оригинальный текст плавно слово за словом появляется на экране поверх окон.
3. **Умный перевод (1 языковая модель):** Параллельно распознанный текст передается в компактную языковую модель, которая переводит фразы на выбранный вами язык и выводит перевод прямо под оригинальной строкой.

## 💻 Системные требования

Поскольку нейросети работают прямо на вашем ПК в реальном времени, для комфортной работы потребуются следующие характеристики:

* **Операционная система:** Windows 10 / Windows 11 (64-bit).
* **Видеокарта (GPU):** NVIDIA с поддержкой CUDA и объемом видеопамяти **от 12 ГБ VRAM**. Модели запустятся и с меньшим объемом, но совместить их работу с играми уже не получится.
* **Свободное место на диске:** **~8-10 ГБ** (для хранения самой программы, портативного окружения и скачиваемых моделей).
* **Оперативная память (RAM):** от 16 ГБ (модель перевода по умолчанию использует процессор и ОЗУ, чтобы не перегружать видеокарту).

## 🚀 Инструкция по запуску (Для обычных пользователей)

### Шаг 1. Подготовка драйверов
Убедитесь, что у вас установлены актуальные драйверы NVIDIA и библиотека [**CUDA Toolkit**](https://developer.nvidia.com/cuda-12-6-0-download-archive) (для проекта используется версия 12.6, но можно изменить в appsettings.json), чтобы модели распознавания речи могли использовать вашу видеокарту.

### Шаг 2. Скачивание программы
1. Перейдите в раздел **[Releases](../../releases)** на странице этого репозитория.
2. Скачайте последний архив `LiveTranslate-Overlay-Portable-win-x64.zip`.
3. Распакуйте архив в любую удобную папку (желательно на SSD-диск и по пути без кириллицы).

### Шаг 3. Первый запуск и загрузка моделей
1. Запустите файл **`LiveTranslate-Overlay.exe`**.
2. При первом запуске программа проверит наличие нейросетевых моделей. Так как их еще нет на диске, откроется окно **«Загрузка необходимых моделей»**.
3. В этом окне вы увидите список моделей, пути их сохранения и общий размер. Нажмите кнопку **«Скачать модели»**. (уазать путь можно в appsettings.json)
4. Дождитесь окончания загрузки (вы будете видеть прогресс и скорость скачивания). После завершения программа автоматически запустит движок.
5. Откроется окно **«История реплик»** с панелью управления (пауза, перезапуск, отметки времени), а в нижней части экрана появится невидимый оверлей для субтитров. Включите любое видео или стрим на английском языке — субтитры начнут появляться автоматически!

## 🛠️ Настройка программы (`appsettings.json`)

Все основные настройки находятся в файле **`appsettings.json`** (или в папке `config/appsettings.json`).

Самые важные параметры, которые вы можете изменить под себя:

* **Версия CUDA (`pytorch.cudaVersion`):**
  * `"cudaVersion": "cu126"` — можно поменять, если уже установлена не CUDA 12.6, а иная версия (но программа может сломаться) 
* **Язык перевода (`translation`):**
  * `"sourceLanguage": "English"` — язык оригинала. (модели распознования по умолчанию обучены только на английском языке)
  * `"targetLanguage": "Russian"` — язык, на который нужно переводить. Вы можете вписать любой другой язык на английском (например, `"German"`, `"Spanish"`, `"French"`).
* **Способ запуска переводчика (`translation.provider`):**
  * `"LlamaCpp"` *(по умолчанию)* — программа сама запускает скачанную модель перевода внутри себя. Никаких сторонних программ открывать не нужно.
  * `"RemoteApi"` — если вы хотите использовать сторонний сервер (например, **LM Studio** или **Ollama**). Адрес сервера настраивается в блоке `remoteApi`.
* **Пути к моделям (`models`):**
  * `"defaultDirectory": "models"` — общая папка, куда по умолчанию скачиваются все модели.
  * `"overridePath": ""` — если какая-то модель уже скачана у вас на компьютере в другом месте, просто укажите полный путь к ней в этом поле, и программа не будет качать её заново. Также вы можете указать свои ссылки в `"downloadUrl"`.
* **Внешний вид и цвета (`ui.overlay`):**
  * `"speakerColors"` — список HEX-цветов для разных собеседников.
  * `"fontSizeMultiplier"` — размер шрифта субтитров на экране.

## 🧠 Используемые модели

По умолчанию программа автоматически скачивает и использует три нейросети:

| Модель | Предназначение |
| :--- | :--- |
| **Multitalker Parakeet Streaming 0.6B v1** *(от NVIDIA)* | Основная модель распознавания речи (ASR) на 600 млн параметров. Превращает потоковый звук в текст с минимальной задержкой. |
| **Streaming Sortformer 4spk v2.1** *(от NVIDIA)* | Модель диаризации спикеров. Определяет, кто именно говорит в данный момент (поддерживает до 4 человек одновременно), и помогает разделять перебивающие друг друга голоса. |
| **Tower-Plus-2B (Q5_K_M GGUF)** | Компактная специализированная языковая модель (LLM) для качественного художественного и разговорного перевода распознанных фраз. |

## 👨‍💻 Инструкция для разработчиков (Запуск в режиме Debug)

Если вы хотите изменить код или запустить проект из исходников в среде разработки (Visual Studio / JetBrains Rider / VS Code):

1. **Клонируйте репозиторий:**
   ```powershell
   git clone https://github.com/FlaweDev/LiveTranslate-Overlay.git
   cd LiveTranslate-Overlay
   ```

2. **Настройте виртуальное окружение Python (требуется Python 3.10–3.11 и менеджер uv или pip)**
   ```powershell
   uv venv .venv --python 3.11
   uv pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu126
   uv pip install -r src/engine/requirements.txt
   ```

3. **Запустите .NET-приложение**
   ```powershell
   dotnet run --project src/ui/LiveTranslateOverlay.csproj
   ```
